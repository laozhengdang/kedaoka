# 发给同学的安装说明

## 最省事的办法：直接发 Release 链接

> https://github.com/laozhengdang/miaomiao-study/releases/latest

同学打开后：

1. 点 `miaomiao-study-v0.9.1.zip`（178MB）下载
2. 解压到任意文件夹
3. 双击 `老郑荡的妙妙小工具.exe`
4. Windows 蓝框提示「已保护你的电脑」→ 点「更多信息」→「仍要运行」

**桌面快捷方式**：第一次打开时程序会自己往桌面放一个快捷方式（不需要手动操作）。
如果没出现，双击程序目录里的 `创建桌面快捷方式.bat` 即可。

**不需要装 Python、不需要装 Node、不需要联网。** 依赖全在包里。

---

## 为什么不能只发仓库链接

仓库里是**源码**，不是程序。拿到源码的人要有：

- Node.js 22+
- Python 3.10+ 且 `pip install pymupdf`
- 联网 `npm install`（会下 100MB 的 Electron）

然后还要敲 `npm start` 才跑得起来。零基础的同学做不到。

**让同学自己的 agent 部署，也卡在同一个地方**：那台电脑得有 Node 和 Python，
而且 agent 得知道怎么用这个仓库（没有一键安装脚本，它要自己摸索）。

---

## 如果同学想用 agent 装

可以把这段话发给他的 agent：

```
这是一个 Electron 桌面应用（兽医课程复习工具），仓库：
https://github.com/laozhengdang/miaomiao-study

请帮我在这台 Windows 机器上跑起来：

1. 确认有 Node.js 22+ 和 Python 3.10+（没有就先装）
2. git clone 到本地
3. npm install
4. pip install pymupdf
5. npm start 启动

注意：
- app/electron/main.mjs 是桌面入口，app/server.mjs 是网页版入口
- 数据默认写到项目下的 data/，可用环境变量 MIAOMIAO_DATA 改
- 第一次启动会要求建学科、导入 PDF
```

---

## 发出去之前你要知道的三件事

**① 不要发你自己的 data 文件夹**

那里有你的课件、卡片和 **API Key**。Release 包里我已经清空了 `data/`，
但如果你手动拷文件夹给同学，记得删掉 data。

**② 同学要不要填 API Key**

不填也能用（导入会按课件排版出卡），但 AI 整理术语、画机制图、生成复习清单都要 Key。
每人用自己的，**不要把你的 Key 发给别人**（账单算你的）。

**③ Windows 会报毒/拦一次**

没买代码签名证书（一年几千块），所以第一次运行必然弹「Windows 已保护你的电脑」。
点「更多信息」→「仍要运行」即可。

## 更新版本时怎么发

改了代码后：

```powershell
node tools/pack.mjs                      # 打包并校验
# 重新压 zip 见 docs/发布清单.md
```

然后 GitHub → Releases → Draft a new release → 新 tag（如 v0.9.1）→ 传新 zip。
同学只要重下 zip 覆盖，`data/` 文件夹保留就还在。
