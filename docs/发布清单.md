# 发布清单（发到 GitHub 之前）

按顺序做，每项都写了「怎么确认」。

## 一、仓库里不能有的东西

- [ ] **课程数据**：`data/` 必须被忽略
  确认：`git ls-files | findstr data` 应该没有输出。
- [ ] **API Key**：只存在本机 `data/db/app.db`，不在仓库里
  确认：`git grep -i "sk-"` 应该只在代码里出现占位符。
- [ ] **私有笔记**：`_probe/` 已从仓库移除（里面有本机路径和当年聊天的原文）
  确认：`git ls-files | findstr _probe` 无输出。
- [ ] **内置运行环境**：`runtime/` 进了 `.gitignore`（65MB，不能进 git）
  确认：`git ls-files | findstr runtime` 无输出。
- [ ] **打包产物**：`build/` 已被忽略
  确认：`git ls-files | findstr build` 无输出。

## 二、仓库必须有的文件

- [x] `LICENSE` —— AGPL-3.0（因为我们打包了 AGPL 的 PyMuPDF）
- [x] `THIRD_PARTY.md` —— 第三方组件与许可说明
- [x] `README.md` —— 面向陌生人：这是什么、怎么用、数据在哪
- [x] `docs/` —— 需求与决策、功能对照、检查清单
- [ ] `.gitattributes` —— 统一换行，避免 Windows 上天天报 LF/CRLF 警告（见下）

建议加：

```
* text=auto eol=lf
*.bat text eol=crlf
*.png binary
```

## 三、发布到 GitHub 的步骤

1. **建仓库**（私有先建，确认干净后再公开）
   ```
   git remote add origin https://github.com/laozhengdang/<repo>.git
   git branch -M main
   git push -u origin main
   ```

2. **看一眼首页**
   GitHub 会把 `README.md` 渲染出来。确认：
   - 图片能显示（`docs/images/*.png` 已提交）
   - 没有裸露的本机路径

3. **做成 Release 给别人下载**
   - 打包成品（`打包.bat`），得到 `build/课到卡/`（约 460MB）
   - **不要把这个目录提交进 git**，用 Release 附件上传 zip
   - Release 说明里写：解压即用、不需要装 Python

4. **在 README 里补一句**：Releases 在哪、当前版本号
