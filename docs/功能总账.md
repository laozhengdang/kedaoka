## 四、你自己没提、但我发现的缺口

| 缺口 | 影响 |
|---|---|
| **多选导入只导第一个**（选 5 个文件只进 1 个） | 批量导课件要一个个来 |
| **小节不能拖拽** | 只能看，不能调 |
| **机制图只认矩形节点** | 椭圆/菱形会当矩形画，曲线不还原 |
| **题库「复习资料」类型仍按课件处理** | 只有考纲和题库有专门解析 |
| **余额只能查 DeepSeek** | 换别家显示「未接入」 |

## 五、结论

- **你在对话里点名的 30 条：全部做到。**
- **A–G 三十个页面：27 完整、1 部分、0 空白。**
- **X1–X10 十个缺口：3 个完整、5 个部分、2 个没做**（冲突日志、预置仓库）。

也就是说：**日常复习这条主线是完整的**（导入 → 整理 → 复习 → 模拟卷 → 统计 → 清单/机制图），
但**"长期维护型"的功能有欠账**——尤其是 X4 冲突日志（课件与 AI 打架时留痕）和 X5 预置仓库（给同学分课程包）。

这两项我更倾向于**先不做**：冲突日志在没有多来源题库之前用不上；预置仓库要等你确实想把课程包发给同学时再做才有意义。
