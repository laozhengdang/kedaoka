# 页面清单（产品全貌）

> 这份文件是"这个工具到底有几个页面、每个页面干什么"的唯一答案。
> 决策依据见 [需求与决策.md](需求与决策.md)（括号里的 D 编号指那份文件的决策）。
> 建立于 2026-10-19，功能讨论到第二十三节时的全量梳理。

---

## 一、导航结构

```
启动画面
  └─ 主窗口（左侧课程栏 + 右侧内容区）
       ├─ 首次引导（仅第一次）
       │    └─ 选专业 → 建课程 → 配 API → 装预置仓库
       │
       ├─ 课程（每个课程一项）
       │    ├─ 今天      → 复习屏 → 结算
       │    ├─ 仓库      → 术语详情 / 章节视图
       │    └─ 更多      → 课程设置、导出、归档
       │
       ├─ 导入（全局入口）
       │    └─ 类型确认 → 预估 → 进度 → 完成 → 抽检
       │
       ├─ 考试（每门课）
       │    └─ 模式选择 → 模拟卷作答 → 成绩 → 错题回流
       │
       ├─ 待办（全局）
       │    ├─ 待修队列（卡有错）
       │    └─ 待审队列（AI 生成的题/答案待确认）
       │
       ├─ 工具（全局）
       │    └─ 专注计时器 / 考试倒计时
       │
       └─ 设置 / 关于
```

## 三、四条主流程

**① 第一次用**
启动 → 引导（选专业 → 建课程 → 配 API → 装预置仓库）→ 主窗口（左侧出现课程）→ 导入第一份课件

**② 导入一份课件**
拖文件 → 确认类型 → 看探测与预估 → 开始 → 看三段进度 → 完成 → 抽检 5 张 → （可选）进审核模式

**③ 日常复习**
点左侧某门课 → [开始今天的 15 张] → 刷 15 张（四档 + 标重点）→ 结算 → 批量复核"不再考"的卡

**④ 考前冲刺**
课程 → 考试模式 → 选档位（如 7 天）→ 看容量校验与降级建议 → 接受 → 每天按计划刷 + 做 2 次模拟卷 → 错题回流
