## 一、最近新加的（优先看这些）

- [ ] **1. 余额**
  左栏最下面 `余额  ¥10.50`。点一下 → 数字闪一下再刷新；鼠标悬停 → 显示"可用 X 元 · 今日 N 次调用"。
  低于 1 元会弹温馨提示。

- [ ] **2. 多选导入**
  进任意课 →「＋ 导入课件到本学科」→「选择文件…」→ **按住 Ctrl 选 2 个 PDF**。
  *应该：* 路径框显示第一个，旁边写"已选 2 个，会依次导入"；导入进度显示"第 1/2 个 · 读页 …"。
  ⚠️ 这会用掉两个真实课件，想省事就只选 1 个看看提示文字对不对。

- [ ] **3. 复习乱序**
  设置 → 显示偏好 → 勾上「复习乱序」→ 保存 → 回课程刷一轮。
  *应该：* 出卡顺序和星级排序不一样了。

- [ ] **4. 导出面板**
  设置 → 往下的「导出」→ 选一门课 →「导出 Markdown」。
  *应该：* 弹保存框，存下来打开看是按章节分的清单；再试「导出 CSV」，Excel 打开不乱码。

- [ ] **5. 备份数据库**
  设置 → 导出 →「备份数据库（.db）」→ 存到桌面。
  *应该：* 得到一个 `.db` 文件，几 MB。

- [ ] **6. 图片查看器**
  病理学 → 仓库 → 点一个有图的词（比如"血栓"）→ 点图。
  *应该：* 全屏黑底，能滚轮缩放、按住拖动、`←/→` 翻到上一张/下一张、Esc 关闭。

- [ ] **7. 名言库**
  设置 → 外观 →「启动名言库」框里写两句（每行一句）→ 保存 → 关掉程序重开。
  *应该：* 启动画面上出现你写的那两句之一。

- [ ] **8. 考试模式**
  课程页 →「考试模式」→ 填一个两周后的日期 →「算一下方案」。
  *应该：* 给出"距考试 14 天，每天新卡 X 张"；如果 X>60 会给降级建议。

- [ ] **9. 学习统计**
  课程页 →「学习统计」。
  *应该：* 7 天柱状图、总进度、累计用时、各章掌握度。

- [ ] **10. 错题本**
  课程页 →「模拟卷」→ 随便做 3 题（故意答错 1 道）→ 交卷 → 看逐题解析 → 点「看错题本」。
  *应该：* 错题本里有那道错题。

- [ ] **11. 待审队列**
  课程页 →「待审」。
  *应该：* 列出 AI 复核刷掉的词（如果之前跑过 AI 整理）。没跑过会显示"没有待审"。

- [ ] **12. 课件批次**
  课程页 →「课件批次」。
  *应该：* 列出每份课件（授课课件/题库/考纲标签 + 页数 + 卡数），每行有「重跑」「移除」。

- [ ] **13. 考前抽检**
  课程页 →「考前抽检」→ 选 5 张。
  *应该：* 随机出题，忘了的会被打回复习队列。
