# 回来后的检查清单

> 按顺序点一遍，每项写了「怎么点」和「应该看到什么」。
> 不符合的把现象记下来，下一次对话直接说编号，例如「12 号不行，弹窗没出来」。

## 零、先跑一次自检（不用点界面）

- [ ] **0. 双击 `自检.bat`**（在 `build\课到卡\` 里）
  *应该：* 弹出一个黑窗口，逐条打勾：没有重名卡片 / 每张卡都有释义 / 没有明显垃圾词 / 机制图几张挂到几张卡……
  最后一行是「没有发现硬伤，可以放心用」。
  报告同时存到 `data\reports\` 里。

  **如果出现 ✗**，把那一行原文发我，比描述一百句都准。

## 一、界面骨架（三栏）

- [ ] **1. 三栏布局**
  打开程序：最左一栏是工具（科目/计时器/主题/其他小工具），中间一栏是课程列表，右边是内容。
  *应该：* 三栏同时可见，互不遮挡。

- [ ] **2. 课程栏收起 / 展开**
  点最左栏底部「‹ 收起课程栏」，再点「› 显示课程栏」。
  *应该：* 收起后课程栏消失，按钮文字变成「› 显示课程栏」，再点一次回来。
  关掉程序重开，应该保持上次的状态。

- [ ] **3. 设置在第一栏**
  点最左栏底部「设置」。
  *应该：* 右边打开设置页，第一栏保持不动。

## 二、科目（专业方向）

- [ ] **4. 切换科目**
  最左栏「科目」下拉，选「草业科学」。
  *应该：* 课程列表只显示草业科学的课（现在是空的，会显示「草业科学下还没有课程」），切回兽医学课程回来。

- [ ] **5. 新建科目 + AI 编提示词**
  科目下拉 →「＋ 新建科目…」→ 输入「水产养殖学」→ 点「让 AI 编提示词」。
  *应该：* 几秒后出现三行内容：
  ```
  术语范围：…
  例子：…
  不抽这些：…
  ```
  再点「保存并切换过去」，科目下拉里就多了这一项。

## 三、计时器

- [ ] **6. 独立计时器（独占全屏）**
  点最左栏的时钟。
  *应该：* 整个窗口进入全屏，屏幕中央一个巨大的时钟，下面是「暂停」「退出专注」。
  点「开始」，数字开始走；点「暂停」停住。

- [ ] **7. 里程碑提醒**
  开始计时后把时间等满 30 分钟。
  *应该：* 屏幕中间那行字变成「已经坐了 30 分钟，喝口水，接着来。」并变蓝。

- [ ] **8. 退出专注**
  按 Esc 或点「退出专注」。
  *应该：* 回到正常界面，且第一栏的时钟还在继续走。

## 四、主题

- [ ] **9. 三套内置主题**
  最左栏「主题」下拉，依次选纸白 / 米黄 / 夜间。
  *应该：* 立刻变色，不用重启。夜间模式下所有文字仍看得清。

- [ ] **10. 自定义主题**
  主题下拉 →「自定义…」→ 改四个颜色 → 点「应用」。
  *应该：* 全界面按你选的颜色变色。
  再点「选择图片…」挑一张图 → 应用。
  *应该：* 背景变成那张图，文字仍然清楚。

- [ ] **11. 首页一句话**
  设置页 →「首页一句话」填 `一天一个概念 —— 老郑` → 保存 → 回首页。
  *应该：* 首页标题下面出现这句话，破折号后面的「老郑」是小字。

## 五、学科与导入

- [ ] **12. 新建学科**
  中间栏底部「＋ 新建学科」→ 填「测试学科」→ 创建。
  *应该：* 侧栏多一门课，自动进入这门课的空页面。

- [ ] **13. 在学科里导入课件**
  进「测试学科」→「＋ 导入课件到本学科」。
  *应该：* 弹窗标题是「导入课件 · 测试学科」，学科名一栏灰掉不能改。

- [ ] **14. 选择文件**
  点「选择文件…」挑一个 PDF。
  *应该：* 路径自动填好，且是完整绝对路径（不是只有文件名）。

- [ ] **15. 拖拽导入**
  从文件夹或微信把 PDF 直接拖进窗口。
  *应该：* 出现虚线框「松手就导入」，松手后弹窗里显示已接收的完整路径。

- [ ] **16. 理论课 / 实验课**
  导入弹窗里选「实验课」再导入。
  *应该：* 导完后，课程页顶部显示「理论 X / 实验 Y」，仓库里点「只看实验课」能看到这批卡。

## 六、AI 相关

- [ ] **17. 导入完成后自动询问**
  导入成功。
  *应该：* 弹出「导入完成 · 学科名」，有两个按钮，下面还有个勾选框「顺便让 AI 把每一章画成机制图」。

- [ ] **18. AI 精修**
  点「现在用 AI 整理」。
  *应该：* 进度窗里逐批显示「处理第 X–Y 页…」「复核删掉 N 条…」，最后显示新增/更新多少张。

- [ ] **19. 一键复习清单**
  课程页「一键复习清单」。
  *应该：* 几秒后出现一份 Markdown 清单，按章分节，每节末尾有「本章逻辑」，最后有「融会贯通」。
  点「导出 Markdown」→ 提示保存路径。

- [ ] **20. AI 画机制图（单张）**
  课程页「机制图」→「让 AI 画一张」→ 范围选「整门课（合成一张）」→ 开始画。
  *应该：* 十几秒后出图，节点从上往下排，最上方是病因/前提，最下方是药物/结果。

- [ ] **21. AI 画机制图（逐章）**
  同上，但范围选「每一章各画一张」。
  *应该：* 一次生成多张，每章一张，最多 6 张。

- [ ] **21a. 考前抽检**
  课程页「考前抽检」。
  *应该：* 随机 15 张（含已经复习过的卡），空格看答案，←记得 / →忘了；
  忘了的会打回复习队列，最后给「还记得 X / 忘了 Y」。

- [ ] **21b. 课件批次**
  课程页「课件批次」。
  *应该：* 列出这门课导入过的每份课件（理论/实验、页数、卡数）。
  点「移除」→ 确认后该批卡片归档；再点「恢复」能回来。

## 七、仓库

- [ ] **22. 出处标记**
  课程 → 仓库 → 随便点一个词。
  *应该：* 每行右边写着「章节 · 第 N 页」，鼠标悬停能看到完整文件名。

- [ ] **23. 只看有图的**
  仓库顶部「只看有图的 N」。
  *应该：* 只剩配了机制图或课件插图的卡，名字后面有个蓝色「图」小标。

- [ ] **24. 卡片详情里的机制图**
  点开「细胞融合」这类词。
  *应该：* 释义下面是「机制图」区块，图里跟你点开的这个词对应的方块是带下划线的。

- [ ] **25. 别名合并**
  卡片详情页「并入其它卡（别名合并）」→ 输入另一个词 → 点它。
  *应该：* 提示「已并入…」，跳到那张卡，原词被存成别名。

## 八、复习流程

- [ ] **26. 四档颜色**
  课程页开始复习。
  *应该：* 四个按钮分别是绿 / 蓝 / 黄 / 红，整块底色，文字是同色系深色；星级是金色。

- [ ] **27. 双计时器**
  复习界面右上角。
  *应该：* 左边是本张用时，右边是「本轮 mm:ss」，两个都在走。

- [ ] **28. 超时只提醒**
  在一张卡上停 90 秒不动。
  *应该：* 本张计时变红，底部提示「这张超时了，凭直觉选一个就行」，但**不会自动帮你选**。

- [ ] **29. 答案页的机制图**
  选档 → 看答案。
  *应该：* 释义下面出现这张卡的机制图（如果它配了图）。

- [ ] **30. 再来一轮**
  刷完当天的一批后，在结算页点「再来一轮（随机 20 张）」。
  *应该：* 立刻排好新的一轮，全部待复习。

- [ ] **31. 模拟考**
  课程页「模拟考」。
  *应该：* 出现一个术语，空格看答案，←/→ 判对错，最后给分数；答错的题会被重置。

- [ ] **32. 待修队列**
  复习时点「释义有误」，然后回课程页点「待修」。
  *应该：* 能看到刚才标记的那张卡，有「恢复」和「查看」按钮。

## 九、数据正确性（这个最容易出问题）

- [ ] **33. 词条没有垃圾**
  三个仓库各翻十几条。
  *应该：* 不应出现「第三章」「主要内容」「简称」「为克隆」「见病症」这类。

- [ ] **34. 出处对得上**
  药理学里点「抗凝血药」「充血性心力衰竭」这类循环系统的词。
  *应该：* 出处写「作用于血液循环系统的药物」，**不是**「消化系统药物」。

- [ ] **35. 没有重复卡片**
  药理学仓库翻一遍。
  *应该：* 同一个词不会连续出现两次。
