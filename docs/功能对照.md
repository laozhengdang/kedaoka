## 我的判断：接下来该补哪些

按"对考试的实际帮助 / 实现成本"排序：

1. **E5 错题本 + E3 逐题解析**——现在答错只是重置，看不到"我错在哪了"，这是复习工具的硬需求
2. **E1/E2 模拟卷升级**——答题卡 + 倒计时 + 成绩页解析，才像真的模拟考
3. **D2 类型确认**（题库/考纲）——生物统计那门课的 `Review.pdf` 是考纲，如果按考纲生成考点树，价值比现在大得多
4. **C5 的三个小按钮**（加入队列 / 就这一张考我 / 查看原文）——成本很低
5. **F5 学习统计**——让人看见进度，长期坚持靠它
6. **A1 启动画面 + B1 首次引导**——给同学用才需要，自己用无所谓
