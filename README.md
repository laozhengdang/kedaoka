# 老郑荡的妙妙小工具

一个给自己和同学用的 **兽医课程复习工具**：把老师发的课件（PDF/PPTX）丢进去，自动整理出重点知识点、名词释义、机制图、易错辨析，然后用「三档自评 + 间隔重复」的方式复习，整门课学完还能出模拟卷。

## 调研得到的关键结论

对 **7 份课件 / 415 页** 全量扫描后：

| 类别 | 页数 | 占比 | 处理方式 |
|---|---|---|---|
| 纯文字页 | 347 | 83.6% | 抽文字 + 颜色 |
| 图注图 | 50 | 12.0% | 图注是文字，可提取，不需看图 |
| 全图无字 | 15 | 3.6% | **唯一需要视觉模型的地方** |
| 白页 | 3 | 0.7% | 丢弃 |

### 1. 只有 15 页需要"看图"，成本可忽略

其中免疫 12 页（单抗制备流程图、NK/NKT 对比表等），病理 2 页，药理 1 页。
**病理解剖基本不需要看图**——它的图注本身就是文字：

```
瘀斑性出血，皮下组织，兔
牛，内毒素血症，心脏，出血
肿瘤性栓子（犬，横纹肌肉瘤）
脂肪性栓塞（兔肾小球）
```

结构极规整：`物种 / 器官 / 病变 / 病因`，解析成字段即可生成图卡。

### 2. 老师的重点信号是「颜色 + 着重号」，**不是加粗**

- 加粗无效：药理/病理整份 PDF 全部文本都是粗体，零信息量
- 颜色是四色体系：`#FF0000` 红=核心术语、`#003399` 深蓝=标题、`#0000FF` 蓝=次重点、`#006633` 深绿=术语
- 全库 **5650 个红字片段**，平均每页 13 个
- 着重号是可精确检测的字符：Wingdings `\uf09f` + 红色，能按坐标关联到被强调的术语
- 坑：药理的 `\uf06c` 只是**项目符号**，不是强调，必须区分

### 3. 老师把考点清单写在章末（但有例外）

| 课件 | 页 | 区块 |
|---|---|---|
| 免疫 3 章 | p36 | 本章要点（5 条）|
| 免疫 4 章 | p56 | 本章重点（7 条）|
| 免疫 5 章 | p33 | 复习思考题（3 条）|
| 药理 消化 | p142 | 思考题 |
| 药理 呼吸 | p43 | 思考题 |
| **病理 两份** | — | **完全没有** |

药理第 2 页还有「学习目标」页，老师自己写了 **了解 / 熟悉 / 掌握** 三级权重。

→ 结论：金标准"有则用、无则退"，程序必须两条路都支持。

### 4. 药理不是"图课"，机制在文字里

药理消化 142 页只有 1 页需要看图。它的机制是成段文字（如谷氨酸/精氨酸的鸟氨酸循环描述）。
所以机制卡要两路造：**免疫从图造**（VLM 出节点+有向边），**药理从段落造**（文本切步骤），最后统一成同一种卡。

## 设计要点（已对齐）

**复习交互**：三档自评 —— ①能想起来（直接跳）②模糊（看解释）③完全不记得（看解释+图+辨析）

**排程**：用「到期队列」而不是纯随机；①间隔×2.5、②基本不动、③重置到 1 天；「模糊」连续两次自动降级（leech 卡）

**存储**：一门课一个库、彼此隔离（防出题串味）；库之上加一层只做链接、不合并内容的「全局术语表」，跨课同名不同义保留多版本溯源

**两套仓库**：给人看的 Markdown + 给机器看的 JSON（可一键分享给同学）

**AI 只在入库阶段跑**，复习阶段纯读本地数据，离线、0 延迟
